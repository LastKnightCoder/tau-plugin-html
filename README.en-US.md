# HTML

Write HTML directly in your documents for layouts and visual effects beyond standard rich text. Insert standalone HTML blocks or embed inline HTML inside a line of text, with Tailwind styling, blog publishing, and document export support.

## Getting Started

1. Install **HTML** from the Plugin Center, enable it on the **Installed** tab, and click **Restart now** on the banner at the top of the Plugins page.
2. Choose **HTML** from the document insert menu, then pick **Block HTML** or **Inline HTML**.
3. Block HTML previews live as you edit and supports full-screen editing; click an **Inline HTML** snippet to edit it, press `Enter` or click outside to confirm, or clear its content to remove it.

When using Tailwind, write full class names rather than dynamically constructed strings. You can also ask the AI assistant to generate HTML snippets for you.

## FAQ

**What happens to HTML when importing Markdown?** Raw HTML tags in Markdown are converted into HTML blocks or inline HTML snippets; HTML inside fenced code blocks stays as regular code.

**Can HTML be edited on read-only pages?** No. Read-only views display the rendered output without allowing edits.

**Will my content be lost if I disable the plugin?** No. The HTML remains saved in your documents and renders again once you re-enable the plugin.

**Why doesn't it show up on mobile?** Mobile apps and the browser extension cannot render this plugin's blocks yet, though your content stays safely stored.

## Tips

- Restart Tau after enabling, disabling, or updating this plugin—the Plugins page will prompt you with **Restart now**.
