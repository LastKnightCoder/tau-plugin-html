# HTML

在文件中直接撰寫 HTML，做出一般文字做不到的排版與效果。可以單獨插入一整塊，也能嵌入一行文字之間，支援 Tailwind 樣式，並可發佈到部落格、隨文件匯出。

## 開始使用

1. 在外掛中心安裝「HTML」，再到外掛頁的「已安裝」裡開啟開關，接著點擊外掛頁頂部提示列上的「立即重啟」，重新啟動後即可使用。
2. 在文件的插入選單中選擇「HTML」，再選「區塊級 HTML」或「行內 HTML」。
3. 區塊級 HTML 可一邊寫一邊預覽，也支援全螢幕編輯；行內 HTML 點一下即可修改，按 Enter 或點擊別處確認，清空內容就會刪除。

使用 Tailwind 時，請將類別名稱完整寫出。也可以請 AI 助手幫你撰寫 HTML 片段。

## 常見問題

**匯入 Markdown 時 HTML 會怎麼處理？** Markdown 中的 HTML 標籤會自動轉換為 HTML 區塊或行內片段；寫在程式碼區塊裡的 HTML 仍保留為一般程式碼。

**唯讀頁面裡能修改嗎？** 不能。唯讀頁面僅供顯示，不會被誤改。

**停用外掛後內容會遺失嗎？** 不會。內容始終儲存在文件中，重新啟用後照常顯示。

**手機上為什麼看不到？** 手機版與瀏覽器擴充功能暫時無法顯示此外掛內容，但資料不會遺失。

## 小提醒

- 開啟、關閉或升級此外掛後，都必須重新啟動 Tau 才會生效，外掛頁會提示「立即重啟」。
